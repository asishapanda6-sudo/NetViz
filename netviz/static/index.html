Watch your network traffic move — and spot trouble at a glance.

NetViz — help

Live network traffic as an animated picture. Shapes = devices (IPs), lines = connections, line color = traffic type. Click any device for details.

Where the traffic comes from

  • 🧪 Simulation — fake demo traffic with built-in attacks (port scan, SYN flood, malware check-in, bulk transfer). Best way to explore — nothing to set up.
  • 📼 PCAP replay — plays a recorded capture file (.pcap) at 0.25×–8× speed, like replaying a video.
  • 🔴 Live capture — watches your real network right now (needs admin/root permission).

What the alerts mean

🎯 Port scanOne device is trying every "door" (port) on another — attackers do this to find a way in
📡 Host sweepOne device is quickly touching many devices — mapping out the network
⚡ SYN floodA flood of fake connection requests trying to knock a device offline (DoS)
📶 C2 beaconingA device "phoning home" to the same server at fixed intervals — classic malware behaviour
☠️ Malicious IPTraffic with an IP from the known-attackers list (blocklist.txt)
🌍 Unusual destinationTraffic going to an anonymizer/proxy — an odd place for normal traffic
📈 Traffic spikeSudden jump several times above the normal level of the last 30s
👁 WatchDevice with unusually many contacts (25+) or open ports (60+)

Reading the picture

  • device inside your network · server on the internet — size = traffic volume
  • Moving dots on a line = packets flowing right now; a pulsing line = active connection
  • red pulsing ring = suspicious device · amber ring = worth watching
  • 🌍 country flags appear next to internet servers (via ip-api.com)
